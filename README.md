# Popup Browser — окно-попап на Chromium

Мини-браузер (движок Chromium через Qt WebEngine) в виде всплывающего окна **поверх всех
окон**. Вставляете ссылку — страница живёт в маленьком окне поверх других приложений;
когда оно мешает — блокируете, и мышь проходит **насквозь**.

## Готовые билды

| Платформа | Что делать |
|---|---|
| **Windows (GitHub Actions)** | залейте папку в репозиторий на GitHub — Actions **сам соберёт exe** и положит zip в **Releases** (см. ниже) |
| **Windows (локально)** | двойной клик `build_windows.bat` → `dist\PopupBrowser\PopupBrowser.exe` |
| **Linux x64** | готовый билд рядом с папкой: `popup-browser-linux64.tar.gz` → распаковать, запустить `PopupBrowser/PopupBrowser` |

Билд содержит Chromium (~470 МБ в распакованном виде — это норма для Chromium).

## Автосборка на GitHub: залил → релиз собрался сам

В проекте уже лежит workflow `.github/workflows/release.yml`:

1. Создайте репозиторий на GitHub и загрузите содержимое папки
   (папка `.github` обязательна — в ней workflow).
2. Всё автоматически:
   - **push в `main`/`master`** → Actions собирает exe под Windows (windows-latest),
     вырезает лишние модули Qt, пакует `PopupBrowser-vX-win64.zip`
     и **сразу публикует его в Releases** (без артефактов Actions);
   - **push тега `v1.2.3`** → релиз с версией `v1.2.3`;
   - либо вручную: вкладка **Actions → Build & Release (Windows) → Run workflow**
     (можно указать версию, например `v1.0.1`).
3. Готовый файл: **Releases → последний релиз → `PopupBrowser-vX-win64.zip`**.
   Распакуйте и запустите `PopupBrowser.exe` — Python не нужен.

Номер версии: тег → указанная при ручном запуске → `v0.0.<номер сборки>` (авто).

## Возможности (по ТЗ)

- ✅ Ссылка вставляется в адресную строку, страница открывается в том же окне
- ✅ Режим попапа: окно всегда поверх других приложений, без панели задач
- ✅ Блокировка окна: курсор и клики проходят сквозь окно (окно «не наезжает» под мышку)
- ✅ Разблокировка: **ПКМ по значку в трее → «Разблокировать окно»**
- ✅ Адресная строка с кнопками (обновить и др.) появляется **только при наведении** мыши
- ✅ Система кеша: HTTP-кеш, cookie, localStorage сохраняются между запусками (`data/`)
- ✅ Chromium (Qt WebEngine)
- ✅ Минимальное потребление ОЗУ: GPU-композитинг выключен, 1 renderer-процесс,
  кеш ограничен 100 МБ (реально ~120–200 МБ — это минимум для полноценного Chromium)
- ✅ **ПКМ по странице → «✂ Вырезать элемент»**: клик по ненужному блоку скрывает его;
  правило сохраняется для сайта и автоматически применяется при каждой загрузке
- ✅ **Возврат вырезанного ↩**: ПКМ по странице → «↩ Вернуть вырезанное» (или кнопка ↩
  на панели, или ПКМ по трее → «↩ Вернуть вырезанное») — список скрытых элементов
  сайта; клик по правилу возвращает элемент, «Вернуть всё» сбрасывает весь сайт
- ✅ **ПКМ по странице → «</> Редактировать HTML»**: правка исходного кода страницы

## Быстрый старт (Windows)

1. Установите Python 3.10+ с python.org (галочка **Add to PATH**).
2. Двойной клик по `run_windows.bat` — первый запуск сам установит PySide6.
3. Ссылку можно передать сразу: `run_windows.bat https://example.com`
   или вставить в адресную строку (наведите мышь на окно).

## Сборка exe (Windows)

1. Двойной клик по `build_windows.bat`.
2. Готовый портативный билд: `dist\PopupBrowser\PopupBrowser.exe`
   (папку `dist\PopupBrowser` можно переносить на любой ПК, Python там не нужен).
3. Если SmartScreen предупреждает о неизвестном издателе — «Подробнее → Выполнить в любом случае».

## Быстрый старт (Linux / macOS)

```bash
pip install -r requirements.txt
python main.py https://example.com
```

## Управление

| Действие | Как сделать |
|---|---|
| Открыть ссылку | навести мышь на окно → вставить в адресную строку → Enter |
| Обновить страницу | кнопка ⟳ на панели, ПКМ по странице, или ПКМ по трее → «Обновить» |
| Заблокировать (клики насквозь) | 🔒 на панели, ПКМ по странице, или ПКМ по трее |
| Разблокировать | **ПКМ по значку в трее → «Разблокировать окно»** |
| Переместить окно | ⠿ на панели или Ctrl + перетаскивание по странице |
| Изменить размер | ◢ в правом нижнем углу (когда разблокировано) |
| Вырезать элемент | ПКМ по странице → ✂ → клик по ненужному блоку (Esc — выход) |
| Вернуть вырезанное | ↩ на панели, ПКМ по странице → «↩ Вернуть вырезанное»,
  или ПКМ по трее → «↩ Вернуть вырезанное» → выбрать правило / «Вернуть всё» |
| Редактировать HTML | ПКМ по странице → «</> Редактировать HTML» → «Применить» |
| Скрыть / показать окно | ЛКМ по значку в трее |
| Выход | ПКМ по трее → «Выход (освободить память)» |

## Где что хранится (папка `data/`)

| Файл/папка | Что это |
|---|---|
| `data/profile/` | cookie, localStorage, профиль Chromium |
| `data/cache/` | HTTP-кеш (до 100 МБ) |
| `data/hidden_rules.json` | правила «вырезанных» ✂ элементов по сайтам (можно править вручную) |
| `data/state.json` | положение/размер окна, последняя ссылка, режим блокировки |

## Если нужно ещё меньше памяти

- В `main.py` в строке `CHROMIUM_FLAGS` добавьте флаг `--single-process`
  (минус ~40–60 МБ, чуть менее стабильно на тяжёлых сайтах).
- `--disable-gpu` оставьте включённым; верните аппаратное ускорение, только если
  нужно плавное видео (удалите `--disable-gpu`).
- Полностью закрывайте приложение через трей → «Выход», а не Alt+F4
  (Alt+F4 прячет окно в трей, сессия остаётся в памяти).

## Примечания

- Изменения из HTML-редактора живут до перезагрузки страницы. Постоянное скрытие
  элементов — только режимом ✂ (его правила сохраняются).
- При заблокированном окне управление возможно **только через трей** — так и задумано.
- Режим ✂ применяет `display:none !important` с пометкой элемента — вернуть можно
  через меню «↩ Вернуть вырезанное» (панель / ПКМ по странице / трей) либо
  удалением правила из `data/hidden_rules.json` вручную. При возврате восстанавливается
  даже прежний inline-стиль `display`, если у элемента он был.
